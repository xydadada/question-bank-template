# 已知限制

这里记录的是模板会主动停止并保留资料的边界，不是静默降级项。

- 当前 `state.db` 仍以内容 SHA-256 作为旧版文件主键。两个仍存在、路径不同但
  字节完全相同的源文件不能安全地并行保存独立状态，因此程序会停止该资料组并
  要求只保留一份；它不会让两份文件共用批次、Markdown 或删除状态。
- 云端 MinerU、MiMo、真实 WeKnora 和 ChatGPT Workspace 需要下载者自己的账号、
  密钥和内容。CI 只能验证本地逻辑和失败边界，不能替代一次可丢弃样本的真实
  端到端确认。
- 压缩包输入受单包条目数与展开大小限制。不要把来源不可信的深层嵌套压缩包
  直接投入自动处理；外层与内层分别受限，但当前版本没有跨全部嵌套层的统一
  总预算。
- 永久删除使用摘要、目录范围、显式确认和审计记录保护，但文件系统删除与
  SQLite 提交无法组成真正的跨系统原子事务。异常断电后应先查看审计与状态，
  不要手工伪造完成记录。

若这些边界影响使用，优先提交可复现的最小样本；不要绕过安全检查。
